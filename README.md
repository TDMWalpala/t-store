# t_store — Flutter E‑Commerce App

A full-featured e‑commerce mobile application built with **Flutter**, **GetX** for
state management, and **Firebase** (Authentication, Cloud Firestore, and Cloud
Storage) as the backend. The UI follows a clean, modern design system with light
and dark themes, custom widgets, and a scalable feature-based folder structure.

> Built step by step as part of a Flutter e‑commerce course and tracked per
> milestone using `TA-*` feature branches.

## Features

- **Onboarding & Splash** — animated onboarding flow with a native splash screen.
- **Authentication** — email/password sign up, login, email verification, forgot
  password, and password reset via Firebase Auth.
- **User Profile** — read and update user details (name, phone, image) stored in
  Cloud Firestore, including image upload to Firebase Storage.
- **Addresses** — add, list, and select shipping addresses.
- **Shop / Home** — search bar, popular categories, promo banner carousel
  (loaded dynamically from Firestore), and popular products grid.
- **Store** — browse categories with scrolling tabs and sub-categories.
- **Product Details** — image slider, attributes, variations, ratings, and reviews.
- **Cart & Checkout** — cart management, coupon codes, billing address, payment
  section, and a success screen.
- **Orders** — order summary and order history list.
- **Wishlist** — saved products.
- **Settings** — profile menu, theme support (light/dark) and re-authentication.
- **Theming** — centralized colors, typography (Poppins), spacing, shadows, and
  reusable widgets under `common/`.

## Project Structure

```
lib/
├── main.dart                 # App entry point (Firebase + GetStorage init)
├── app.dart                  # GetMaterialApp, theme & initial binding
├── firebase_options.dart     # Generated by FlutterFire CLI
├── navigation_menu.dart      # Bottom navigation shell
│
├── bindings/                 # GetX dependency bindings
│   └── general_bindings.dart
│
├── common/                   # Shared, reusable UI
│   ├── styles/               # Shadows, spacing styles
│   └── widgets/              # App bars, buttons, cards, images, loaders, ...
│
├── data/                     # Data layer
│   ├── repositories/         # Auth, user, categories & banners repositories
│   └── services/             # External / platform services
│
├── features/                 # Feature-first modules
│   ├── auth/                 # Onboarding, login, signup, password config
│   ├── personalization/      # Profile, addresses, settings
│   └── shop/                 # Home, store, cart, checkout, orders, wishlist, ...
│       ├── controllers/
│       ├── models/
│       └── screens/
│
├── localization/             # Localization / i18n
└── utils/                    # Cross-cutting helpers
    ├── constants/            # Colors, sizes, text & image strings
    ├── device/               # Device specific helpers
    ├── exceptions/           # Firebase/Auth/Platform/Format exceptions
    ├── formatters/           # Date, currency & phone formatters
    ├── helpers/              # Helper functions, network manager, pricing
    ├── http/                 # HTTP client utilities
    ├── local_storage/        # Local storage wrapper
    ├── logging/              # Logger setup
    ├── popups/               # Snackbars & loaders
    ├── theme/                # App themes & widget themes
    └── validators/           # Form validation
```

Assets live under `assets/` (fonts, icons, images, animations, logos) and are
declared in `pubspec.yaml`.

## Getting Started

### Prerequisites

- [Flutter SDK](https://docs.flutter.dev/get-started/install) `>= 3.0.5`
- Dart `>= 3.0.5`
- Android Studio / Xcode (or a connected device / emulator)
- A [Firebase](https://console.firebase.google.com) project
- [FlutterFire CLI](https://firebase.flutter.dev/docs/cli/) (for Firebase setup)

Check your environment:

```bash
flutter doctor
```

### Installation

```bash
# 1. Clone the repository
git clone https://github.com/TDMWalpala/t-store.git
cd t-store

# 2. Install dependencies
flutter pub get

# 3. (Optional) generate the native splash screen
dart run flutter_native_splash:create
```

## Firebase Setup

This project uses **Firebase Authentication**, **Cloud Firestore**, and
**Cloud Storage**.

1. Create a project in the [Firebase Console](https://console.firebase.google.com).
2. Enable the following services:
   - Authentication → **Email/Password** sign-in method
   - Cloud Firestore (start in production or test mode)
   - Cloud Storage
3. Configure the app with the FlutterFire CLI:

   ```bash
   dart pub global activate flutterfire_cli
   flutterfire configure
   ```

   This regenerates `lib/firebase_options.dart` and places the platform config
   file (e.g. `android/app/google-services.json`).

4. Recommended Firestore collections used by the app:

   | Collection     | Purpose                                    |
   | -------------- | ------------------------------------------ |
   | `Users`        | User profile records                       |
   | `Categories`   | Shop categories (`Name`, `Image`, `IsFeatured`, …) |
   | `Banners`      | Promo banners (`ImageUrl`, `TargetScreen`, `Active`) |

   > Keep the document field names in sync with the models in
   > `lib/features/**/models/` (they are case-sensitive).
